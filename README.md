# Kasper - Creative Agency Template

Kasper is a responsive, single-page creative agency website template built with HTML, CSS, and JavaScript. It is based on the "Kasper" PSD template design.

**Live Demo:** https://kasper-new.vercel.app/

## Features

-   **Fully Responsive Design:** Adapts to all screen sizes, from mobile phones to desktops.
-   **Interactive Navigation Menu:** A mobile-friendly toggle menu that automatically closes when a section is selected.
-   **Live Search:** A functional search bar that provides live suggestions based on the site's navigation links.
-   **Testimonial Slider:** A touch-friendly slider to showcase testimonials with an auto-play feature.
-   **Services, Portfolio, and About Sections:** Standard sections to showcase company information.
-   **Contact Form:** A functional contact form for user inquiries.
-   **Smooth Scrolling:** Smooth navigation to different sections of the single page.

## Technologies Used

-   **HTML5**
-   **CSS3**
    -   **Normalize.css:** For resetting browser default styles.
    -   **Font Awesome:** For icons.
-   **JavaScript (ES6)**: For all interactive features like the slider, search, and mobile menu.
-   **webhint**: Linting tool used for checking code quality and best practices.

## Getting Started

To run this project, simply click on the link https://kasper-new.vercel.app/ to open in your web browser.
